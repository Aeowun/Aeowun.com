# AEOWUN

AEOWUN is the home of **AeoEngine** and **AeoScript**.

**AeoEngine** is a 3D voxel game engine and editor for building worlds, running simulations, and making games.

**AeoScript** is the gameplay scripting language used by AeoEngine.

This repository contains the AEOWUN website, documentation, tutorials, and reference material for both projects.

## AeoEngine

AeoEngine provides the tools and runtime for creating games with:

* 3D voxel worlds
* World building and editing
* Lighting
* Physics and collision
* Characters and cameras
* Runtime systems
* Integrated gameplay scripting
* An editor for building and testing worlds

Learn more:

https://aeowun.com/aeoengine/

## AeoScript

AeoScript is the scripting language built for AeoEngine.

It is used to define gameplay behavior, respond to events, interact with world cells and entities, control runtime properties, and build game systems.

Learn more:

https://aeowun.com/aeoscript/
