MAGY

REASONING IS NOT AUTHORITY.

PROBLEM

MODEL CLAIMS

If a model can declare a task complete, the system is trusting language instead of the project.

CHANGE

RUNTIME VERIFICATION

MAGY separates Planner and Executor from the runtime. Restricted writes and commands require operator approval. Completion depends on a verification command.

RESULT

EVIDENCE DECIDES

Model output is not treated as proof of completion. Failure output is fed back into the loop. MAGY remains alpha, local-first, and in progress.

MAGY architecture · github.com/Aeowun/Magy (public description: emergency backup)

AEOPIN

INSTALLERS FAIL CLOSED.

PROBLEM

UNTRUSTED PAYLOADS

A download that cannot check what it is installing leaves the operator guessing.

CHANGE

AUTHORITY RELEASE

AEOPIN v1.2.3 verifies the matching portable payload, installs the managed application, and uses SHA-256 validation with an atomic update and recovery flow.

RESULT

FAIL CLOSED

The installer fails closed when integrity checks do not pass. The current Windows release is the verified GitHub release, not a side channel.

AEOPIN product page · changelog · github.com/Aeowun/Aeopin

CHECKMAKER

SMALL CHANGE. SMALL DIFF.

PROBLEM

REWRITE CHURN

Most Markdown editors rewrite an entire document to toggle a checkbox.

CHANGE

SURGICAL WRITE

CheckMaker seeks the exact checkbox byte and changes only that marker. External drift is detected before a write.

RESULT

REFUSE STALE WRITES

Line endings, encoding, and surrounding content stay put. An old view cannot silently overwrite newer work.

CheckMaker · github.com/Aeowun/Checkmaker
