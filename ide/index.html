PROJECT MODEL

CODE IS A STRUCTURE.

AEOWUN maintains a project model that connects the physical filesystem to the structure and relationships inside the source. CodeGraph exposes that model as a navigable surface instead of reducing the project to a folder tree. 

Project
├── Region
│   └── Subsystem
│       └── Component

├── Type-Uses
