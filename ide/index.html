WORKSPACE

SAME IDE CAPABILITY. LESS PERMANENT UI.

AEOWUN uses a dynamic panel model instead of keeping every tool visible at the same time. Explorer, terminal, project analysis, assistant, and other surfaces can be opened, closed, resized, layered, and rearranged as the current task requires.

DYNAMIC PANELS

Tools are available when needed instead of permanently consuming workspace area.

DYNAMIC TABS

Editors and terminal sessions share a flexible tab model rather than a fixed collection of views.

RESIZABLE REGIONS

Horizontal and vertical panel boundaries can be adjusted directly to fit the current workflow.

LAYERED WORKSPACE

Workspace surfaces can be combined rather than forcing a single rigid layout.

PERSISTENT STATE

Project, editor, window, and workspace state persist across launches.

COMMAND SYSTEM

Commands are centrally registered and exposed through menus and keyboard shortcuts.
