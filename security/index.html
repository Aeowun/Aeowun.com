SECURITY

Security information and vulnerability reporting for AEOWUN software and services.

REPORT A VULNERABILITY

If you believe you have found a security vulnerability affecting AEOWUN software or this website, please report it directly rather than publishing sensitive details in a public issue.

SECURITY REPORTING support@aeowun.com

INCLUDE

  • The affected product or page.
  • The version or revision involved, when known.
  • Clear steps to reproduce the issue.
  • The expected behavior and the observed behavior.
  • Any relevant impact or security boundary involved.

DO NOT INCLUDE

  • Passwords or authentication secrets.
  • Private keys, tokens, or credentials.
  • Private user data that is not necessary to demonstrate the issue.

RESPONSE

Security reports are reviewed as they are received. Response time can vary depending on the issue and available information. Fixes, mitigations, and disclosure decisions are handled on a case-by-case basis.

PUBLIC PROJECTS

Many AEOWUN projects are developed in public repositories. A public repository does not make sensitive vulnerability details appropriate for a public issue. Use the reporting address above when the issue has a security impact.
