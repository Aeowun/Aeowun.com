01 THE SYSTEM
AUTONOMOUS SOFTWARE ENGINEERING RUNTIME

Not an IDE. A runtime.

Most AI development tools begin with a conversation and attempt to produce a useful answer.

AEOWUN begins with the project itself. It maintains workspace state, coordinates tools, manages execution, evaluates results, and records evidence of what actually happened.

The language model is not the system. It is one source of cognition inside the system.

04 FAILURE HISTORY
RECURSIVE REASONING LOOP DETECTION / CONTAINMENT

The system repeatedly executed failed steps for an extended period. A validation watchdog was introduced to detect repetitive failure and force termination instead of allowing an uncontrolled reasoning loop.

DETERMINISTIC OFF-LOADING LLM / SOFTWARE BOUNDARY

Small models repeatedly failed deterministic tasks such as JSON manipulation and symbol lookup. Those responsibilities were moved into deterministic software logic and Tree-sitter analysis.

CLOSED-LOOP VERIFICATION AEGIS / CONTINUOUS MONITORING

Network containment required continuous verification rather than a one-time decision. Flow deltas are compared against active containment state to detect potential breaches.
