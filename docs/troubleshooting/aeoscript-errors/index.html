AEOSCRIPT ERRORS

Detailed reference for common AeoScript runtime errors and diagnostics.

AEOWUN // SUPPORT

RUNTIME ERRORS

INDEX OUT OF BOUNDS

Occurs when attempting to access a basket element at an index that is negative or greater than or equal to the basket's length. Always verify the index against basket.len() before access.

MUTATING FROZEN BASKET

Occurs when calling mutation methods (like insert, remove, or clear) on a basket that has been marked as read-only via basket.freeze(). Frozen baskets are reference-shared and cannot be modified.

INVALID ENGINE HANDLE

Occurs when performing operations on an engine handle (Cell or Entity) that refers to an object that has been destroyed or removed from the simulation. Long-lived handles should be validated before use.

BUDGET EXHAUSTION

Occurs when a script fiber exceeds its allocated operation limit (default 100,000) during a single execution slice. This prevents runaway scripts from blocking the main engine thread. Use wait() to yield in heavy loops.

CALL DEPTH EXCEEDED

Occurs when nested user-function calls exceed the maximum stack depth (default 64). This protects the runtime from unbounded recursion or excessively deep call chains.

PRINT OUTPUT

DIAGNOSTICS

The AeoEngine Print Output terminal provides structured diagnostics for every script failure. Understanding these fields is critical for debugging complex entity behaviors.

DIAGNOSTIC FIELDS

  • SEVERITY Indicates if the message is a fatal Error (halts execution) or a Warning (diagnostic only).
  • SCRIPT PATH The relative path to the .aeo source file where the failure originated.
  • ENTITY ID/NAME The unique numeric identifier and authored name of the Cell or Entity owning the script.
  • CONTEXT The name of the function or lifecycle hook (e.g., update, on_ready) executing at the time of error.
  • MESSAGE A descriptive string explaining the specific nature of the runtime failure.
