DEVELOPER REFERENCE

Technical specifications and internal architecture details for contributors and engine developers.

ENGINE INTERNALS

ARCHITECTURE OVERVIEW

SCRIPT RUNTIME & FIBERS

The AeoScript execution subsystem manages script fibers (ScriptFiber) through a cooperative scheduler. Suspensions via wait() yield fiber execution without blocking the main engine loop. Top-level statements run within a file-level instance while entity methods execute within allocated ScriptInstance environments.

ENGINE HOST & BRIDGE

Communication between AeoScript bytecode interpretation and native Rust engine systems occurs via the EngineHost trait and ScriptHostBridge. Handles carry Lightweight IDs (HandleKind, u64) resolved at runtime without transferring ownership.

PHYSICS SIMULATION

AeoEngine's physics pipeline runs on a fixed-step loop. Dynamic rigid bodies and character controllers evaluate AABB and voxel static grid collisions independently from rendered frame deltas.

PERSISTENCE & OVERRIDES

The World subsystem maintains a clean firewall between authored spatial data and runtime Play-mode overrides. Play-mode mutations modify volatile runtime state maps, leaving the authored world serialization files untouched.
