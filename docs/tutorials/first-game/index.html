FIRST GAMEPLAY EXAMPLE

This tutorial demonstrates runtime object creation and movement scripting. It is an engine scripting exercise rather than a complete game project.

GOAL

This tutorial will combine everything you have learned so far. You will orchestrate object spawning, live spatial position overrides, and cooperative loop mechanics to build an active, moving platform hazard stage sequence.

PREREQUISITES

  • — Tutorial 4: Runtime Cell — Spawning containers via program execution scripts.
  • — Tutorial 3: Interactive Object — Fiber suspension hooks and visibility structures.

WHAT YOU WILL BUILD

You will write a complete script block that dynamically registers a high-contrast orange hazard elevator element at simulation start, and cycles its structural world coordinate position up and down indefinitely every second.

STEP-BY-STEP INSTRUCTIONS

  1. Initialize the Game Asset File: Within your open editor session, create a new source asset file inside scripts/ labeled moving_hazard.aeo.
  2. Establish the Core Lifecycle Entry: Declare the base fn on_ready() initializer statement block inside your editor text viewer.
  3. Instantiate the Interactive Hazard: Call the constructor routine to generate a dynamic voxel structure: const platform = cell.new("Block"). Give it a distinct orange hue: platform.color = [1, 0.5, 0].
  4. Formulate the Infinite Translation Loop: Insert a while true block directly under the allocation code to keep the fiber executing across frames.
  5. Override Spatial Coordinates with Yields: Inside the loop, assign the lower position vector: platform.position = [5, 2, 5] and yield for one second: wait(1.0). Next, override it to the upper position: platform.position = [5, 5, 5] and add another wait(1.0) yield state.
  6. Bind and Launch: Bind your master script component to any base floor block anchor in the 3D viewport. Trigger full execution by clicking Play or tapping F5. Watch the dynamic orange elevator transition smoothly between layers. Press Escape to stop play testing.
MOVING_HAZARD.AEO AEOSCRIPT 
// moving_hazard.aeo - Spawning and coordinate translation loop
fn on_ready() {
    // 1. Allocate dynamic runtime block
    const platform = cell.new("Block")
    platform.color = [1, 0.5, 0]

    // 2. Continuously translate spatial positions
    while true {
        platform.position = [5, 2, 5]
        wait(1.0)

        platform.position = [5, 5, 5]
        wait(1.0)
    }
}

EXPLANATION

This script showcases the absolute integration between AeoScript's asynchronous fiber scheduler and AeoEngine's runtime memory pipeline. By invoking platform.position = [...], the script triggers an atomic spatial rewrite within the voxel translation grid during Play mode. Since the operations run inside a lightweight cooperative fiber thread, the sequential code reads as a synchronous script while operating completely in parallel with physics, rendering, and input loops.

RESULT

As soon as simulation begins, a glowing orange platform cell spawns cleanly and immediately starts shifting between vertical heights 2 and 5 exactly every one second, creating a functional, interactive mechanics stage block.
