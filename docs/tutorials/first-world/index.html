FIRST WORLD

Learn the basics of AeoEngine editor navigation, building geometry, placing lights, and playing your world.

GOAL

This tutorial will guide you through the fundamental workflows of the AeoEngine Voxel Editor. You will learn how to navigate the 3D viewport, construct voxel layouts, add environmental lighting, and simulate the world in Play mode.

PREREQUISITES

  • — AeoEngine Core Overview — Understanding the architecture of the engine.
  • — Getting Started — Setting up your environment.
  • — Documentation Hub — Technical background of the AEOWUN workspace.

WHAT YOU WILL BUILD

You will construct a clean, physical stage featuring a solid brick floor, an elevated platform, and a Light cell that illuminates the scene during simulation.

STEP-BY-STEP INSTRUCTIONS

  1. Launch AeoEngine and Create a Project: Open AeoEngine, choose "New Project" from the startup dialog, name your project FirstWorld, and select a folder location.
  2. Master Editor Navigation: In the viewport, hold the Right Mouse Button (RMB) to enter free-move mode and move the mouse to aim the camera. While holding RMB, use W to move forward, S to move backward, A to move left, and D to move right. Hold the Middle Mouse Button (MMB) to orbit around the current editor target; move the mouse left, right, up, or down to orbit.
  3. Build a Solid Floor: Select Build. Open Block: Block ▼ and choose Cube. Open Rendering ▼, set Texture: to brick, then left-click and drag across the grid to create a 10x10 floor.
  4. Add an Elevated Platform: Keep Build and Cube selected. Point at the top of the floor, then left-click and drag a 2x2 area to build the platform one cell above it.
  5. Place a Light: With Build selected, open the Block: Block ▼ type menu and choose Light. Point at the top of the platform and left-click in the viewport to place the Light cell above it.
  6. Test in Play Mode: Press Play to start the simulation. Runtime simulation changes do not replace the authored World data.
STRUCTURAL DATA MODEL JSON 
{
  "world": {
    "cells": [
      { "type": "Block", "position": [0, 0, 0], "texture": "brick" },
      { "type": "Light", "position": [5, 4, 5], "color": [1.0, 1.0, 1.0] }
    ]
  }
}

EXPLANATION

In this workflow, your primary interactions use the AeoEngine Voxel Pipeline. When you paint voxels, the engine populates an uncompressed cell coordinate map. Adding a Light cell provides authored lighting for the world. Upon transitioning to Play mode via F5, the engine performs a complete isolated copy of the authored scene data into a volatile runtime cache, ensuring that play tests never destructively mutate your master source file.

RESULT

In Play mode, you should see the brick floor and elevated platform illuminated by the Light cell above them.
