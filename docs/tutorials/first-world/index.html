FIRST WORLD

Learn the basics of AeoEngine editor navigation, building geometry, placing lights, and playing your world.

GOAL

This tutorial will guide you through the fundamental workflows of the AeoEngine Voxel Editor. You will learn how to navigate the 3D viewport, construct voxel layouts, add environmental lighting, and simulate the world in Play mode.

PREREQUISITES

  • — AeoEngine Core Overview — Understanding the architecture of the engine.
  • — Getting Started — Setting up your environment.
  • — Documentation Hub — Technical background of the AEOWUN workspace.

WHAT YOU WILL BUILD

You will construct a clean, physical stage featuring a solid brick floor, an elevated platform, and an ambient light bulb actor that illuminates the scene dynamically during simulation.

STEP-BY-STEP INSTRUCTIONS

  1. Launch AeoEngine and Create a Project: Open AeoEngine, choose "New Project" from the startup dialog, name your project FirstWorld, and select a folder location.
  2. Master Editor Navigation: Click inside the 3D Viewport. Hold the Right Mouse Button (RMB) and move your mouse to look around. Use the W, A, S, and D keys while holding RMB to fly through the empty void.
  3. Build a Solid Floor: Select the Block tool from the left toolbar panel. Ensure the texture brush is set to brick.png. Left-click and drag across the grid origin to build a 10x10 voxel floor.
  4. Add an Elevated Platform: Move your brush onto the center of the newly constructed floor. Single left-click a few times to stack blocks vertically, creating a small 2x2 pedestal.
  5. Place a Light Source: Open the "Actor Palette" panel on the right side of the editor window. Drag a Light component into the viewport and place it directly above your elevated platform pedestal.
  6. Test in Play Mode: Press the Play button located at the top center of the editor toolbar (or hit F5). The editor grid disappears, physics engines activate, and your environment is rendered with live directional lighting. Press Escape to stop simulation and return to Editor mode.
STRUCTURAL DATA MODEL JSON 
{
  "world": {
    "cells": [
      { "type": "Block", "position": [0, 0, 0], "texture": "brick.png" },
      { "type": "Light", "position": [5, 4, 5], "color": [1.0, 1.0, 1.0] }
    ]
  }
}

EXPLANATION

In this workflow, your primary interactions use the AeoEngine Voxel Pipeline. When you paint voxels, the engine populates an uncompressed cell coordinate map. Adding the Light actor dynamically injects an illumination matrix into the rendering loop. Upon transitioning to Play mode via F5, the engine performs a complete isolated copy of the authored scene data into a volatile runtime cache, ensuring that play tests never destructively mutate your master source file.

RESULT

Upon clicking Play, you should see a crisp, illuminated grid of brick blocks casting shadow volumes onto the void beneath. The light bulb glows intensely, demonstrating live ray casting across your voxel pedestals.
