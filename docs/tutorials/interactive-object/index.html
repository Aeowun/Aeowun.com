INTERACTIVE OBJECT

Learn how to manipulate cell visibility and leverage cooperative fibers with wait states to script dynamic temporal behaviors.

GOAL

This tutorial demonstrates how to implement automated temporal behaviors on voxel blocks. You will learn to control cell properties asynchronously over time using cooperative script fibers and non-blocking wait operations.

PREREQUISITES

  • — AeoScript Specification — Specifically the sections on Fibers and Cooperative Yielding.
  • — Tutorial 2: First Script — Managing script files and binding objects via the Properties layout.

WHAT YOU WILL BUILD

You will implement a script that loops indefinitely, causing an authored block actor to transition cleanly between invisible and visible states at 0.25-second intervals, producing a smooth "flash" visual behavior.

STEP-BY-STEP INSTRUCTIONS

  1. Create the Flash Script File: Within your active project, navigate to the Asset Browser, right-click your scripts/ directory, choose New File, and name it flash_behavior.aeo.
  2. Implement a Loop in the Initialization Hook: Double-click the file to open the code area. Define the fn on_ready() function. Inside this function, insert a continuous while true control statement.
  3. Manipulate Visibility Overrides: Inside the loop block, assign visible = false to turn off rendering. Follow this immediately with a wait(0.25) yield call.
  4. Restore Visibility: Set visible = true to toggle the render state back on, and add another wait(0.25) yield statement to hold the frame configuration.
  5. Bind the Script to a Target: Click on your elevated pedestal block in the viewport. Go to the Properties Panel, select the Script Binding selector, map it to flash_behavior.aeo, and hit apply.
  6. Observe the Asynchronous Execution: Run Play mode by hitting F5. Watch the designated block flash in and out of existence continuously while you fly around the stage. Press Escape to close the runtime cache session.
FLASH_BEHAVIOR.AEO AEOSCRIPT 
// flash_behavior.aeo - Non-blocking visibility oscillation
fn on_ready() {
    while true {
        visible = false
        wait(0.25)
        visible = true
        wait(0.25)
    }
}

EXPLANATION

Traditional script runtimes block the main application thread when executing sleep operations. AeoScript avoids this through Cooperative Fibers. When wait(0.25) is reached, the virtual machine freezes the block's current call stack, local instruction pointers, and loop variables, returning control to the main game engine loop. After 0.25 seconds have elapsed, the scheduler wakes the fiber, resuming precisely where it paused without executing the initialization sequence again.

RESULT

In Play mode, the designated pedestal block cleanly disappears and reappears exactly 4 times per second, acting as an interactive hazard or indicator light without dragging down framerates or blocking physical collision queries.
