INSTALLATION

AEOPIN is currently available for Windows 10 and 11.

1. Download the AEOPIN installer.
2. Run AEOPIN_Setup.exe.
3. Follow the on-screen instructions.

CAPTURE

To keep a file or folder, simply drag it onto the AEOPIN window. You can also use the global hotkey ALT + SHIFT + V to summon the appliance instantly.
