CHECKMAKER

A small Markdown checklist editor. Check a box without rewriting the rest of the file.

DOWNLOAD v1.0.0 VIEW SOURCE

The Windows release is a standalone CheckMaker.exe from the GitHub V1.0.0 tag. No installer and no Python installation are required to run the published build.

WHY IT EXISTS

CHANGE THE CHECKBOX. NOT THE DOCUMENT.

A normal Markdown editor can rewrite an entire document when one checkbox changes. That can affect line endings, encoding, or other bytes that had nothing to do with the edit. CheckMaker takes a narrower approach: find the checkbox marker and change those bytes directly.

THE CURRENT RELEASE

SEE IT WORK.

This demo comes from the public CheckMaker repository. The application renders the Markdown for viewing, while checkbox changes are handled separately and written directly to the file.

BYTE-LEVEL WRITE

LEAVE THE FILE ALONE

CheckMaker locates the checkbox marker, seeks to its byte offset, and writes the new marker. Surrounding content, line endings, and encoding are not rewritten as part of the checkbox change.

DRIFT PROTECTION

CHECK BEFORE WRITING

Before changing a file, CheckMaker verifies that the file has not changed externally and that the expected checkbox marker is still present at the target location.

OFFLINE

NO CLOUD REQUIRED

The published Windows build contains its required assets and runs locally without an internet connection.

TABS

MULTIPLE FILES

Multiple Markdown documents can be open in one session. Tab IDs are UUID-based so actions remain associated with the correct document.

INPUT

OPEN A FILE YOUR WAY

Use drag-and-drop, the native file picker, or paste a path. Recent files remember the last 10 documents.

GIT-FRIENDLY

SMALL DIFFS

When a checkbox changes, the resulting Git diff can remain a single marker instead of showing an entire document as rewritten.

HOW IT WORKS
MARKDOWN FILE
  ↓
MARKDOWN RENDERER
  ↓
NATIVE WEBVIEW VIEWER
  ↓
CHECKBOX CLICK
  ↓
VERIFY FILE STATE
  ↓
BINARY BYTE SEEK + WRITE
  ↓
SAME FILE

Viewing and modification are separate operations. A checkbox write is only performed when CheckMaker can verify the expected file state. Configuration history is written atomically, and file IO uses fsync so the change is flushed to storage.

SCOPE

IT DOES ONE THING ON PURPOSE.

CheckMaker is a checklist editor, not a full Markdown IDE. It is not intended to replace VS Code, Obsidian, or a general-purpose writing application.

GFM-style task items are recognized, including nested lists. Tab reordering and in-file search remain unfinished items in the public roadmap.

RELEASE
