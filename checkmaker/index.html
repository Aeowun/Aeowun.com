CHECKMAKER

Check boxes. Touch nothing else. A surgical Markdown checklist editor for people who care about predictable files and tiny diffs.

DOWNLOAD v1.0.0 VIEW SOURCE
THE PROMISE

SMALL CHANGE. SMALL DIFF.

Most Markdown editors rewrite an entire document for a checkbox toggle. CheckMaker seeks to the exact checkbox byte and changes only that marker, preserving line endings, encoding, and surrounding content.

SURGICAL EDITS

PRESERVE THE FILE

Only the checkbox marker changes. No formatting churn or accidental document rewrite.

DRIFT PROTECTION

REFUSE STALE WRITES

External changes are detected before a write so an old view cannot silently overwrite newer work.

OFFLINE READY

NO CLOUD REQUIRED

Assets are bundled locally and the standalone Windows release runs without an internet connection.

RELEASE

v1.0.0 IS AVAILABLE.

The first public Windows release is available from GitHub. CheckMaker is intentionally focused: it is a surgical checklist editor, not a replacement for a full Markdown authoring environment.
