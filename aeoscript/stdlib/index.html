STANDARD LIBRARY

Deterministic gameplay utilities across math, collections, and strings.

AEOSCRIPT // ENGINE

OVERVIEW

WHAT YOU'LL LEARN

  • — Navigating built-in namespaces: math, basket, string
  • — Using deterministic mathematical operations
  • — Leveraging method routing for baskets
  • — Working with Unicode-aware string utilities

CORE CONCEPT

The AeoScript Standard Library provides a focused set of utilities designed for gameplay logic. Organized into namespaces (math, basket, string), these functions ensure deterministic results across different platforms. Baskets, the primary collection type, even support method-style routing for a more intuitive developer experience.

SYNTAX / WORKFLOW

EXAMPLES

NAMESPACES & ROUTING SYNTAX 
math.clamp(val, min, max) // Namespace call
basket.insert(items, 0, val) // Namespace call
items.insert(0, val) // Method routing style
METHOD CALLS EXAMPLE 
const speed = math.clamp(velocity, 0, 10)
const roll = math.random(1, 6)

const words = string.split("Hello World", " ")
words.sort()
debug.log("Alphabetical:", words[0])

EXPLANATION: Standard library functions can be called via their namespace (e.g., math.clamp). For baskets, the VM automatically routes method calls (e.g., words.sort()) to the basket namespace, passing the object as the first argument.

COMMON NOTES / LIMITATIONS

string operations are Unicode-scalar-aware, treating multi-byte characters correctly.

math.random() returns 0.0-1.0 (float) or min-max (inclusive int) depending on arguments.

Custom comparator functions for basket.sort() are not currently supported; sorting is ascending by default.
