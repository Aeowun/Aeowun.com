WORKING WITH WORLD ITEMS

Open doors, hide coins, and toggle collision properties while your game is running.

LESSON 6

1. WHAT YOU'RE MAKING

Once you've found an item in your level, your script can change how it looks and behaves during Play mode! In this lesson, you'll open a door by hiding its graphics and letting the player walk through.

CODE

2. WORKING EXAMPLE

AEOFILE DOOR_CONTROL.AEO 
const doors = find("Doors")

// Open all doors in the level
for door in doors {
  door.visible = false
  door.solid = false
}

// Wait 1 second before closing them again
wait(1)

for door in doors {
  door.visible = true
  door.solid = true
}
BREAKDOWN

3. LINE-BY-LINE BREAKDOWN

`door.visible = false`: Hides the 3D door block so it becomes invisible.

`door.solid = false`: Turns off physical collision so characters can walk right through!

`wait(1)`: Keeps the doors open for exactly 1 second before closing them.

TRY IT YOURSELF

4. TRY CHANGING SOMETHING

Try changing `wait(1)` to `wait(3)`. Run your game in AeoEngine to see the door stay open three times longer before locking shut!

5. COMMON BEGINNER MISTAKE

Forgetting `door.solid = false`: If you only set `door.visible = false`, the door will disappear visually, but players will still bump into an invisible wall!

Play Mode Resets: Property changes made by scripts only last during Play mode. When you stop playing, your level restores its original saved state!
