FUNCTIONS

Encapsulating reusable logic into named blocks with parameters and return values.

AEOSCRIPT // FUNDAMENTALS

CORE CONCEPT

Functions are the primary unit of logic in AeoScript. They can be declared at the top level or within entities. Functions support recursion, parameters, and return types, and their local state is fully preserved when execution yields via wait().

SYNTAX / WORKFLOW

EXAMPLES

FUNCTION DECLARATION SYNTAX 
fn name(p: type): return_type { ... }
const anonymous = fn(p) { ... }
object:method() // Method-style call
DAMAGE CALCULATION EXAMPLE 
fn calculate_damage(atk: number, def: number): number {
  return math.max(1, atk - def)
}

final_dmg = calculate_damage(25, 10)

const door = cell.get(101)
door.open = fn() {
  self.visible = false
}
door:open()

EXPLANATION: This function takes two numbers, calculates their difference, and ensures a minimum return value of 1. The result is then stored and logged.

COMMON NOTES / LIMITATIONS

Functions may omit a return type if they do not return a value.

Parameters can be explicitly typed or inferred if types are omitted.

Method calls use the colon : syntax, which is often used for engine object interactions.
