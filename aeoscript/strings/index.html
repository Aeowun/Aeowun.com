STRINGS

Working with UTF-8 Unicode text and standard string operations.

AEOSCRIPT // FUNDAMENTALS

OVERVIEW

WHAT YOU'LL LEARN

  • — Creating string literals with ""
  • — Unicode-aware scalar manipulation
  • — String concatenation with +
  • — Using the string namespace functions

CORE CONCEPT

Strings in AeoScript are immutable sequences of UTF-8 encoded text. All string operations are Unicode-aware, meaning that functions like string.len() and splitting operate on Unicode scalar values rather than raw bytes, ensuring safety for international characters and emoji.

SYNTAX / WORKFLOW

EXAMPLES

STRING CONCATENATION SYNTAX 
text = "Hello, World!"
combined = "User: " + username
length = string.len(text)
UNICODE OPERATIONS EXAMPLE 
const name = "Ghost"
const greeting = "Hello " + name

debug.log(string.upper(greeting))
debug.log("Scalar count: " + string.len("é")) // Outputs 1

EXPLANATION: This script demonstrates string concatenation and the use of the string namespace. It also highlights Unicode safety, where a character like 'é' is correctly identified as a single scalar value.

COMMON NOTES / LIMITATIONS

Strings are immutable; operations return new strings rather than modifying the original.

Scalar-based operations prevent "half-character" errors when dealing with multi-byte UTF-8 sequences.

Concatenation requires the left side to be a string or be compatible with string conversion.
