CONDITIONS & LOOPS

Make game decisions with if statements and repeat actions across multiple objects with loops.

LESSON 3

1. WHAT YOU'RE MAKING

Games need to make choices: "If player health reaches 0, trigger Game Over" or "For every coin in the level, make it collectible." In this lesson, you'll learn `if` conditions and `for` loops.

CODE

2. WORKING EXAMPLE

AEOFILE GAME_DECISIONS.AEO 
health = 0
game_over = false

// Checking player health
if health <= 0 {
  game_over = true
  debug.log("Game Over! Respawning...")
} else {
  debug.log("Player is still alive!")
}

// Loop through all coins placed in the World
const coins = find("Coin")

for coin in coins {
  coin.visible = true
  coin.solid = true
}
BREAKDOWN

3. LINE-BY-LINE BREAKDOWN

`if health <= 0`: Asks AeoEngine if `health` has dropped to 0 or less. If true, it runs the code inside the `{}` block.

`else`: Runs if the condition was false (when the player has more than 0 health).

`for coin in coins`: Repeats the enclosed instructions for every single coin found in your 3D level.

TRY IT YOURSELF

4. TRY CHANGING SOMETHING

Try changing `health = 0` to `health = 50`. Run your script again and see how the `else` block runs instead, printing `"Player is still alive!"`!

5. COMMON BEGINNER MISTAKE

Forgetting Curly Braces `{}`: In AeoScript, all `if` blocks and `for` loops require opening and closing curly braces `{}`.

Confusing `=` and `==`: Use `=` to set a variable (`health = 100`). Use `==` to check if two things are equal (`if health == 100`).
