CONTROL FLOW

Directing the execution of code using conditional logic and iteration.

AEOSCRIPT // FUNDAMENTALS

OVERVIEW

WHAT YOU'LL LEARN

  • — Conditional logic with if, else if, and else
  • — Indefinite iteration using while loops
  • — Collection iteration with for-in
  • — Yielding inside loops with wait()

CORE CONCEPT

Control flow structures allow scripts to respond to dynamic game states. AeoScript's loops and conditionals are "fiber-safe," meaning they can be suspended using wait() and will resume exactly where they left off without losing loop state or local variables.

SYNTAX / WORKFLOW

EXAMPLES

CONDITIONALS & LOOPS SYNTAX 
if condition { ... } else { ... }
while condition { ... }
for item in collection { ... }
ITERATION & WAITING EXAMPLE 
const enemies = find("Orc")

for enemy in enemies {
  if enemy.health <= 0 {
    enemy:translate(1, 0, 0)
  } else {
    enemy.color = [1, 0, 0]
  }
  wait(0.1) // Yield after each enemy processing
}

EXPLANATION: This script iterates through a basket of enemies, destroying those with no health and highlighting survivors. The wait(0.1) inside the loop ensures the processing doesn't block the engine for a single frame.

COMMON NOTES / LIMITATIONS

The for loop iterates over Baskets, which are ordered sequences.

All control flow blocks must be enclosed in curly braces {}.

Loop state is preserved during fibers, making complex timed sequences easy to write.
