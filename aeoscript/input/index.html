INPUT & MOUSE APIS

Query player movement input, jump requests, and control OS mouse cursor visibility and screen locking.

AEOSCRIPT // GAMEPLAY

OVERVIEW

WHAT YOU'LL LEARN

  • — Querying directional movement vectors via input.get_move_vector()
  • — Detecting jump key presses with input.is_jump_pressed()
  • — Accessing the mouse handle via const mouse = get.mouse()
  • — Toggling cursor visibility and screen locking dynamically

CORE CONCEPT

AeoScript provides simple, high-level input queries for player controllers and UI menus. The input namespace supplies 2D movement vectors and jump state. The mouse handle, obtained via get.mouse(), lets scripts toggle mouse.setCursorVisible and mouse.setScreenLocked at runtime independently of camera controllers. World settings establish initial Play-mode defaults, which scripts can override dynamically.

SYNTAX / WORKFLOW

EXAMPLES

MOUSE CONTROL SYNTAX 
const mouse = get.mouse()

// Show cursor and unlock from window (e.g. for pause menu)
mouse.setCursorVisible = true
mouse.setScreenLocked = false
PLAYER INPUT EXAMPLE 
fn update(dt) {
  const move = input.get_move_vector()
  const move_x = move[0]
  const move_z = move[1]

  if input.is_jump_pressed() && player.is_grounded() {
    player.apply_vertical_impulse(6.5)
  }
}

EXPLANATION: input.get_move_vector() returns the current 2D movement input [x, z]. get.mouse() accesses the global mouse controller.

API SUMMARY

input.get_move_vector(): Returns 2D movement basket [vx, vz].

input.is_jump_pressed(): Returns boolean indicating jump key status.

get.mouse(): Returns the singleton Mouse handle (`id: 0`).

mouse.setCursorVisible / mouse.setScreenLocked: Booleans controlling OS cursor visibility and window capture.
