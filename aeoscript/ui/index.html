BUILDING GAME UI

Create health displays, gold counters, panels, and game-over screens with AeoScript.

LESSON 9

1. WHAT YOU'RE MAKING

Players need to see their health, gold, and score on screen while playing. In this lesson, you'll create a HUD (Heads-Up Display) with UI panels and text elements that update when game events fire!

CODE

2. WORKING EXAMPLE

AEOFILE HUD_DEMO.AEO 
// Create UI elements
const hud_panel = ui.new("Panel")
const health_text = ui.new("Text")
const gold_text = ui.new("Text")

hud_panel.size = [220, 76]
hud_panel.color = [0.05, 0.05, 0.05, 0.80]

health_text.color = [1.0, 1.0, 1.0, 1.0]
gold_text.color = [1.0, 0.85, 0.25, 1.0]

health_text.text = "HEALTH: 100 / 100"
gold_text.text = "GOLD: 0"

// Listen for health changes from the Player Manager
on on_health_changed(current, maximum) {
  health_text.text = "HEALTH: " + current + " / " + maximum
}

// Listen for gold changes when coins are collected
on on_gold_changed(total_gold) {
  gold_text.text = "GOLD: "
  gold_text.text += total_gold
}
BREAKDOWN

3. LINE-BY-LINE BREAKDOWN

`ui.new("Panel")` / `ui.new("Text")`: Creates a new UI object on the player's screen.

`hud_panel.color = [r, g, b, a]`: Sets the panel color with Red, Green, Blue, and Alpha (transparency).

`gold_text.text += total_gold`: Appends the new gold number directly onto the string `"GOLD: "`.

TRY IT YOURSELF

4. TRY CHANGING SOMETHING

Try positioning your HUD at the top right of the screen using `const viewport = ui.get_viewport_size()` and setting `hud_panel.position = [viewport[0] - 240, 20]`!

5. COMMON BEGINNER MISTAKE

Setting `text` on a `Panel`: `Panel` elements do not have text! Assign `.text` to `Text` or `Button` elements instead.

Color Values: Color values in AeoEngine range from `0.0` to `1.0` (not 0 to 255). Pure white is `[1.0, 1.0, 1.0, 1.0]`.
