ENTITIES

Defining persistent scriptable objects with fields and behavior.

AEOSCRIPT // CORE OBJECTS

OVERVIEW

WHAT YOU'LL LEARN

  • — Declaring entities with the entity keyword
  • — Defining authored fields for persistent state
  • — Implementing member functions
  • — Binding scripts to World objects

CORE CONCEPT

Entities are the bridge between AeoScript and the AeoEngine World. An entity declaration defines the structure and behavior of an authored object. Fields within an entity maintain their state persistently on the specific object instance they are bound to.

SYNTAX / WORKFLOW

EXAMPLES

ENTITY DECLARATION SYNTAX 
entity Name {
  field: type = value
  fn method() { ... }
}
ENTITY METHODS EXAMPLE 
entity Door {
  locked: bool = false
  key_id: number = 101

  fn try_open(id: number): bool {
    if !locked || id == key_id {
      locked = false
      return true
    }
    return false
  }
}

EXPLANATION: This Door entity defines a persistent locked state and a key_id. The try_open function encapsulates the logic for unlocking the door based on a provided ID.

COMMON NOTES / LIMITATIONS

Entity fields maintain state between executions and frames.

Lifecycle hooks (like update) can be defined inside entities.

Scripts must be bound to a World object instance in the editor for the entity logic to activate.
