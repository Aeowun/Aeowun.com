TYPE SYSTEM

The fundamental building blocks of data in AeoScript, from primitives to engine handles.

AEOSCRIPT // FUNDAMENTALS

OVERVIEW

WHAT YOU'LL LEARN

  • — Primitive types: number, bool, string, nil
  • — Collection types: basket, map
  • — Engine handles: Cell, Entity
  • — Optional (nullable) type annotations

CORE CONCEPT

AeoScript features a small, focused type system designed to handle gameplay logic efficiently. It distinguishes between primitive values, which are passed by value, and complex collections or engine handles (like Cells), which use reference semantics.

SYNTAX / WORKFLOW

EXAMPLES

TYPE ANNOTATIONS SYNTAX 
identifier: type = value
identifier: type? = nil // Optional type
const name: string = "Ghost"
TYPE CHECKING EXAMPLE 
health: number = 100
name: string = "Ghost"
target: Entity? = nil

if target != nil {
  target:destroy()
}

EXPLANATION: Explicit type annotations ensure that variables store the expected data formats. The Entity? type allows the target variable to either hold a valid handle or be empty (nil).

COMMON NOTES / LIMITATIONS

number is always a 64-bit floating-point value.

string is UTF-8 Unicode text; operations are Unicode-scalar-aware.

Cell handles represent authored World objects, while Entity handles represent live runtime objects.
