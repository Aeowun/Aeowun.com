MATH

Utilizing deterministic mathematical functions for gameplay logic.

AEOSCRIPT // FUNDAMENTALS

OVERVIEW

WHAT YOU'LL LEARN

  • — Basic operations (abs, min, max, clamp)
  • — Trigonometry (sin, cos, tan)
  • — Random number generation
  • — Rounding and square roots

CORE CONCEPT

The math namespace provides a set of deterministic mathematical operations. Determinism is critical for synchronized gameplay and predictable physics interactions. The library covers everything from basic rounding to complex trigonometric functions and bounded random number generation.

SYNTAX / WORKFLOW

EXAMPLES

MATH FUNCTIONS SYNTAX 
val = math.abs(-10)
clamped = math.clamp(health, 0, 100)
roll = math.random(1, 6)
RANDOM & CLAMPING EXAMPLE 
const velocity = 5.7
const speed = math.clamp(velocity, 0, 10)

const roll = math.random(1, 20)

if roll == 20 {
  debug.log("Critical Success!")
}

EXPLANATION: This script uses math.clamp to ensure a velocity stays within bounds and math.random(min, max) to generate an inclusive integer for a d20 roll simulation.

COMMON NOTES / LIMITATIONS

math.random() without arguments returns a float in the range [0.0, 1.0).

math.random(min, max) returns an integer in the inclusive range [min, max].

Angles for trigonometric functions are in radians.
