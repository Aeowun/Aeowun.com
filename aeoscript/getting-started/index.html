GETTING STARTED

CORE CONCEPT

An AeoScript source file is a sequence of top-level declarations and executable statements. Top-level statements execute exactly once when the world loads, allowing for system initialization and global configuration. Detailed behavior is documented in the Syntax guide.

SYNTAX / WORKFLOW

EXAMPLE

SYNTAX COMMENTS & LOGGING 
// Use double slashes for single-line comments
debug.log("Text to display in console")
EXAMPLE STARTUP LOGIC 
debug.log("System initializing...")

const version = 1.0

if version > 0 {
  debug.log("Startup successful.")
}

EXPLANATION: This script logs initialization messages to the engine console and sets a persistent version constant. The if block checks a condition during the initial load.

COMMON NOTES / LIMITATIONS

Top-level statements: Run within a "Global" script instance for the file.

Execution order: Follows source order (top-to-bottom).

Yielding: Top-level code supports yielding using wait().
