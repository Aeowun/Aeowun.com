YOUR FIRST SCRIPT

AEOENGINE SCRIPT EDITOR
GETTING STARTED:

3. Press Enter.

LESSON 1

1. HELLO WORLD

You are going to create a startup script for your game world. When you press Play, AeoEngine runs your script and prints the message to the output window so you can see that your script is working.

CODE

2. EXAMPLE

AEOFILE STARTUP.AEO 
// This is a comment — AeoEngine ignores lines starting with //
debug.log("Hello, World!")
BREAKDOWN

3. LINE-BY-LINE BREAKDOWN

Line 1 (// ...): Lines starting with two slashes // are comments. They are notes for yourself and do not run in the game.

Line 2 (debug.log(...)): Tells AeoEngine to print the message "Hello, World!" into the output panel at the bottom of the editor.

TRY IT YOURSELF

4. TRY CHANGING SOMETHING

Try replacing the text inside the quotation marks with your own message. Click Play at the top of AeoEngine and look at the Output tab at the bottom to see your new text.

DEBUGGING

5. COMMON BEGINNER MISTAKES

Missing Quotes: Text inside debug.log() must be wrapped in matching quotation marks like "Hello". Writing debug.log(Hello) makes AeoScript look for a value named Hello instead of treating it as text.

Unlinked Script: Make sure the script is attached to the appropriate world or cell so AeoEngine knows where it should run.

Misspelled Names: Code names must match exactly. For example, debug.log() is different from debug.logg().

Missing Parentheses: Make sure every opening ( has a matching closing ). For example, debug.log("Hello") is complete, while debug.log("Hello" is not.

Ignoring the Error: When something does not work, read the error message first. It can often tell you what went wrong and where AeoEngine found the problem.
