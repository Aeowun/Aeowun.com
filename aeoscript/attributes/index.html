CUSTOM ATTRIBUTES

Store custom game variables directly on World items using cell.attributes.

AEOSCRIPT // GAME DATA

OVERVIEW

WHAT YOU'LL LEARN

  • — Storing custom variables on Cells with cell.attributes["key"] = value
  • — Reading and modifying attributes during Play mode
  • — Replacing and removing values during Play mode
  • — Removing an attribute by assigning nil

CORE CONCEPT

Cells in AeoEngine can store custom key/value data called attributes. Attach or replace a value at runtime with cell.attributes["key"] = value. Assigning nil removes that attribute from the active play session.

SYNTAX / WORKFLOW

EXAMPLES

CELL ATTRIBUTES SYNTAX 
cell.attributes["health"] = 100 // Attach custom attribute
current_hp = cell.attributes["health"] // Read custom attribute
cell.attributes["health"] = nil // Remove attribute
HEALTH & STATE SYSTEM EXAMPLE 
fn setup_chest(chest: Cell) {
  chest.attributes["opened"] = false
  chest.attributes["gold"] = 50
}

fn open_chest(chest: Cell) {
  if chest.attributes["opened"] == false {
    chest.attributes["opened"] = true
    const gold = chest.attributes["gold"]
    debug.log("Found gold: ", gold)
  }
}

EXPLANATION: cell.attributes["key"] attaches custom game state directly to a Cell object, making it easy to create chest mechanics, health bars, or door keys without complex data structures.

COMMON NOTES / TIPS

Flexible Values: An attribute can hold ordinary script values, such as a number, string, boolean, basket, map, or function.

Play Session Scope: Attributes attached during play belong to the active runtime state and do not change the authored Cell set.

Clearing Data: Assigning nil removes the attribute.
