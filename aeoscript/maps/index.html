MAPS

Storing key/value pairs for flexible data organization.

AEOSCRIPT // COLLECTIONS

OVERVIEW

WHAT YOU'LL LEARN

  • — Creating maps with literal syntax {}
  • — Using string and numeric keys
  • — Handling missing keys and nil
  • — Deleting keys via nil assignment

CORE CONCEPT

A map is a reference-backed key/value collection. Unlike baskets, maps are not positional sequences. They allow for rapid data retrieval based on specific keys. Maps support dynamic growth, and assigning nil to an existing key effectively removes it from the collection.

SYNTAX / WORKFLOW

EXAMPLES

MAP OPERATIONS SYNTAX 
data = { name: "Ghost", level: 1 }
val = data["name"]
data["new_key"] = "value"
data["old_key"] = nil // Delete key
KEY ACCESS EXAMPLE 
const stats = {}
stats["health"] = 100
stats[1] = "numeric key"

debug.log(stats["health"])

if stats["mana"] == nil {
  debug.log("Mana stat not found")
}

EXPLANATION: This example shows how to add entries to a map and how to check for the existence of a key by comparing its value to nil. It also highlights that numeric and string keys are distinct.

COMMON NOTES / LIMITATIONS

Reading a missing key always returns nil.

Numeric keys and string keys are distinct: map[1] and map["1"] refer to different entries.

Identifier keys in literals (e.g., { name: "..." }) are treated as string keys.
