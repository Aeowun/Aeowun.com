LANGUAGE SYNTAX

Understanding the lexical structure, case sensitivity, and statement termination in AeoScript.

CORE CONCEPT

AeoScript is a case-sensitive language that uses newlines to terminate statements. It is designed to be concise, omitting the need for semicolons while maintaining clear structural boundaries through blocks and indentation. All syntax rules are enforced by the engine's parser. For details on initialization, see Getting Started.

SYNTAX / WORKFLOW

EXAMPLES

STATEMENTS & BLOCKS GRAMMAR 
identifier = value // Newlines terminate statements
if condition {
  // Braces define blocks
}
CASE SENSITIVITY EXAMPLE 
fn update(dt) {
  // Case matters
  health = 100
  // Health = 100 // This would be a different variable

  if health <= 0 {
    die()
  }
}

EXPLANATION: This function demonstrates case sensitivity (health vs Health) and the use of braces for control flow. Statements are separated by newlines rather than semicolons.

COMMON NOTES / LIMITATIONS

Whitespace is mostly ignored except as a separator between tokens.

Keywords like entity, fn, const, and if cannot be used as identifiers.

Comments start with // and continue to the end of the line.
