CORE LANGUAGE

HOW AEOSCRIPT WORKS

ENTITIES & FUNCTIONS

Define reusable gameplay logic with functions, persistent state, and runtime object handles. 

fn spawn_enemy(position) {
      const enemy = spawn("Enemy", position)

      enemy.health = enemy_health
      enemy.animation = "Idle"

      basket.insert(enemies, enemy)
    }

WAITING & DELAYS

Pause a running script with wait(seconds). Execution resumes from the same point later. 

for target in doors {
      target.visible = false
    }

    wait(1)

    for target in doors {
      target.visible = true
    }

EVENTS & INTERACTIONS

React to gameplay events and connect separate systems without tightly coupling their implementation. 

on on_gold(amount) {
      gold += amount
      score += amount * 10

      event.fire("on_coin")
      event.fire("on_gold_changed", gold)
    }

BASKETS & COLLECTIONS

Store and manage groups of objects with baskets for enemies, doors, coins, spawn points, and other gameplay data. 

enemies: basket = []

    basket.insert(enemies, enemy)

    for enemy in enemies {
      if enemy.alive {
        // ...
      }
    }

EVENT-DRIVEN SYSTEMS

Split gameplay into small systems that announce events while other scripts decide how to respond. 

// Door system
    event.fire("door_open")

    // Environment system
    on door_open() {
      door_sound.sound.play()
    }

RUNTIME ENTITIES & AI

Control runtime characters from scripts with position, velocity, facing, health, animation, jumping, and AI behavior. 

if distance <= detection_range {
      enemy.velocity = [
        direction_x * move_speed,
        enemy.velocity[1],
        direction_z * move_speed
      ]

      enemy.facing = [
        direction_x,
        direction_z
      ]

      enemy.animation = "Walk"
    }
