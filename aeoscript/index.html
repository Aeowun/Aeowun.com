AEOSCRIPT

Gameplay scripting language for AeoEngine, featuring resumable fibers, persistent state, and deep engine integration.

ENTITIES & FUNCTIONS

AeoScript uses entity declarations to define scripted objects. Fields maintain persistent state between executions, and functions can be typed. Everything interacts with engine handles like Cell and Entity. 

entity Player {
  health: number = 100

  fn take_damage(amount: number) {
    health = math.max(0, health - amount)
  }

  fn get_health(): number {
    return health
  }
}

RESUMABLE FIBERS

AeoScript uses cooperative fibers for yielding execution. The wait(seconds) operation suspends execution and resumes later, retaining the entire call stack, local variables, and loop state. 

fn flash() {
  visible = false
  wait(0.25)
  visible = true
}

TYPES & COLLECTIONS

Basic types include number, bool, string, and nil. Collections like basket (sequences) and map (key/value) use reference semantics; const prevents reassignment but allows collection mutation. 

const ids = [1, 2]
ids[0] = 99

const stats = { score: 10 }
stats["score"] = stats["score"] + 5

CONTROL FLOW

AeoScript supports standard if, while, and for loops. Top-level statements execute once on load, while lifecycle hooks like on_ready() and update(dt) drive ongoing entity behavior. 

for item in collection {
  item:action()
}

if health <= 0 {
  die()
}
