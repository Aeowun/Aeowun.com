AEOSCRIPT

A clear, simple gameplay scripting language built for making games in AeoEngine.

CORE LANGUAGE

HOW AEOSCRIPT WORKS

ENTITIES & FUNCTIONS

Define game objects using entity. Fields store data like health or speed, and functions run logic when called. 

entity Player {
  health = 100

  fn take_damage(amount) {
    health = math.max(0, health - amount)
  }
}

WAITING & DELAYS

Pause script execution easily with wait(seconds). The script remembers its exact place and continues later. 

fn flash_light() {
  light.visible = false
  wait(0.5)
  light.visible = true
}

EVENTS & INTERACTIONS

React to player collisions, triggers, and game events with simple handlers like on_touch(cell) and on EventName. 

fn on_touch(cell) {
  debug.log("Player touched a coin!")
  cell.visible = false
}

LISTS & MAPS

Store sequences of items in baskets (lists) and key/value data in maps to manage inventory and stats. 

const inventory = ["Key", "Sword"]
const stats = { hp: 100, gold: 25 }
