MATH API

Deterministic mathematical operations for gameplay simulation.

AEOSCRIPT // API

OVERVIEW

The math namespace provides a suite of deterministic mathematical functions. These ensure consistent simulation behavior across different platforms and hardware by avoiding floating-point drift in critical gameplay logic.

MATH METHODS

SPECIFICATION

Method Parameters Returns Description
math.abs(x) x: number number Returns the absolute value of x.
math.min(...) numbers number Returns the smallest numeric argument.
math.max(...) numbers number Returns the largest numeric argument.
math.floor(x) x: number number Largest integer ≤ x.
math.ceil(x) x: number number Smallest integer ≥ x.
math.round(x) x: number number Rounds to nearest integer.
math.sqrt(x) x: number number Square root of x.
math.pow(b, e) b, e: number number b raised to power e.
math.sin(x) x: number number Sine of x (radians).
math.cos(x) x: number number Cosine of x (radians).
math.tan(x) x: number number Tangent of x (radians).
math.clamp(v, min, max) v, min, max number Restricts v to [min, max].
math.lerp(a, b, t) a, b, t number Linear interpolation: a + (b-a)*t.
math.deg_to_rad(d) d: number number Converts degrees to radians.
math.rad_to_deg(r) r: number number Converts radians to degrees.
USAGE

EXAMPLE

HEALTH CLAMPING EXAMPLE 
const raw_health = 120
const max_health = 100

const health = math.clamp(raw_health, 0, max_health)
debug.log("Effective Health: ", health) // Outputs 100

NOTE: math.clamp produces a runtime error if min > max.

BEHAVIOR / NOTES

Determinism: All math functions are designed to produce bit-identical results across supported engine targets.

Angles: Trigonometric functions (sin, cos, tan) expect arguments in radians. Use deg_to_rad for conversion.
