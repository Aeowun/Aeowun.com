ENTITY HANDLE

Reference interface for live runtime objects.

AEOSCRIPT // API

OVERVIEW

An Entity handle refers to a live runtime object such as a Player, NPC, or projectile. Unlike authored Cells, Entities are dynamic instances created and managed by the engine during simulation and are governed by runtime state rules.

ENTITY PROPERTIES

SPECIFICATION

Property Type Access Description
.id number Read-only Unique runtime Entity ID.
.name string Read-only Entity instance name.
.position basket Read-only Current world position [x, y, z].
USAGE

EXAMPLE

RUNTIME DISCOVERY EXAMPLE 
const players = find("Player")
for p in players {
  debug.log("Player at: ", p.position)
}

EXPLANATION: find returns a basket of handles which may include both Cells and Entities depending on the name match.

BEHAVIOR / NOTES

Lifecycle: Entity handles become invalid when the referenced object is destroyed or removed from the simulation. Accessing properties on an invalid reference produces a runtime error.

Reference Semantics: Entity handles are lightweight references. Assigning them to variables or passing them to functions does not copy the underlying object.
