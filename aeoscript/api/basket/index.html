BASKET API

Reference interface for sequence collections.

AEOSCRIPT // API

OVERVIEW

A basket is a zero-indexed, reference-backed sequence. Baskets are the primary collection type for ordered data in AeoScript. They support mixed types and provide reference semantics, meaning aliases share the same underlying data.

INSERTION SYNTAX 
basket.insert(b, pos, value)
BASKET METHODS

SPECIFICATION

Method Parameters Returns Description
basket.create(c, [v]) count, [value] basket Creates a basket of size c.
basket.insert(b, [p], v) b, [pos], val nil Inserts value at position.
basket.remove(b, [p]) b, [pos] any Removes and returns element.
basket.clear(b) b: basket nil Removes all elements.
basket.find(b, v, [i]) b, val, [init] num/nil Finds first matching index.
basket.move(s, a, b, t, [d]) src, a, b, t, [dst] nil Range copy/move utility.
basket.concat(b, [s], [i], [j]) b, [sep], [i], [j] string Joins elements into a string.
basket.clone(b) b: basket basket Returns a shallow copy.
basket.freeze(b) b: basket nil Marks basket as read-only.
basket.sort(b) b: basket nil Sorts elements in ascending order.
basket.len(b) b: basket number Returns the number of elements.
USAGE

EXAMPLE

BASKET METHODS EXAMPLE 
const inventory = ["Sword", "Shield"]
basket.insert(inventory, "Potion")

debug.log(basket.len(inventory)) // Outputs 3
inventory.sort()

EXPLANATION: Namespace functions can be called directly or as methods on the basket instance (e.g., inventory.sort()).

BEHAVIOR / NOTES

Reference Semantics: Assigning a basket to a new variable creates an alias. Use basket.clone() if an independent copy is required.

Zero-Based: The first element is always at index 0.

Overlapping Moves: basket.move is guaranteed to be overlap-safe when the source and destination baskets are the same.
