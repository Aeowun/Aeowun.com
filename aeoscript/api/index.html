AEOSCRIPT // API

OVERVIEW

The AeoScript API provides the interface between scripted gameplay logic and the AeoEngine runtime environment. It includes a deterministic standard library for math and collections, as well as handles for interacting with the authored World and live runtime entities.

GLOBAL FUNCTIONS

CORE API

Function Description
debug.log(...) Writes a message to the engine diagnostics/output system.
find(name) Finds Cells or Entities by their authored name or identity. Returns a basket.
getAllCellsOfClass(class) Returns a basket of all Cells matching the specified class type (e.g., "Block").
wait(seconds) Suspends fiber execution for the specified duration. See Waiting.
