SCRIPT EVENTS & TOUCHES

Detect player collisions with on_touch and send game signals across scripts using event.fire().

LESSON 7

1. WHAT YOU'RE MAKING

In game making, objects talk to each other through events. A trap doesn't manage player health directly — when stepped on, it fires an "on_damage" event! Another script (the Player Manager) receives that event and reduces player health.

CODE

2. WORKING EXAMPLE

TRAP SCRIPT TRAPS.AEO 
const traps = find("Trap")

for trap in traps {
  trap.on_touch = fn(c) {
    debug.log("Trap touched by:", c.id)
    event.fire("on_hurt")
    event.fire("on_damage", 10)
  }
}
PLAYER MANAGER EVENT LISTENER 
// Listen for the on_damage event anywhere in the game
on on_damage(amount) {
  health = math.max(0, health - amount)
  event.fire("on_health_changed", health, max_health)
}
BREAKDOWN

3. LINE-BY-LINE BREAKDOWN

`trap.on_touch = fn(c)`: Runs automatically whenever a character contacts the trap block. `c` is the handle of the object that touched it.

`event.fire("on_damage", 10)`: Broadcasts the `"on_damage"` event with `10` damage across the whole game.

`on on_damage(amount)`: Receives the event in your Player Manager script and subtracts the damage amount!

TRY IT YOURSELF

4. TRY CHANGING SOMETHING

Try changing `event.fire("on_damage", 10)` to `25` on a lava block script. Walk into the lava in AeoEngine to see a quarter of your health bar vanish instantly!

5. COMMON BEGINNER MISTAKE

Event Name Mismatch: `event.fire("on_damage")` and `on on_damage()` must use the exact same spelling. If you write `event.fire("damage")`, `on on_damage()` will never trigger!

Forgetting Arguments: If an event fires with a number (`10`), your listener must accept that parameter (`on on_damage(amount)`).
