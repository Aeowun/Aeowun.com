PUTTING IT ALL TOGETHER

See how coins, traps, doors, HUD UI, and audio connect together in a complete AeoEngine game.

LESSON 11

1. WHAT YOU'RE MAKING

In this final lesson, you'll see how separate gameplay scripts talk to each other to create a complete game loop!

ARCHITECTURE

2. THE GAME FLOW

EVENT FLOW STARTER WORLD ARCHITECTURE 
Coin / Trap / Door
       │
       │ event.fire("on_gold" / "on_damage" / "door_open")
       ▼
Player Manager (Owns Health & Gold State)
       │
       ├────► event.fire("on_health_changed") ──► HUD Script (Updates Text)
       │
       └────► event.fire("on_coin") ───────────► Environment Script (Plays Audio)
CANONICAL EXAMPLE COIN PICKUP CHAIN 
// 1. Coin detects touch and announces value
coin.on_touch = fn(c) {
  event.fire("on_gold", value)
  coin.visible = false
  coin.solid = false
}

// 2. Player Manager updates game state and notifies HUD & Audio
on on_gold(amount) {
  gold += amount
  event.fire("on_coin")
  event.fire("on_gold_changed", gold)
}

// 3. HUD Script updates the UI
on on_gold_changed(total) {
  gold_text.text = "GOLD: "
  gold_text.text += total
}

// 4. Environment Script plays sound
on on_coin() {
  coin_sound.sound.play()
  wait(1)
  coin_sound.sound.stop()
}
BREAKDOWN

3. LINE-BY-LINE BREAKDOWN

`One script owns game state`: The Player Manager script is the single owner of `health` and `gold`. Coins and traps don't change player variables directly.

`Objects report what happened`: Coins fire `on_gold`, traps fire `on_damage`, and doors fire `door_open`.

`Presentation scripts react`: The HUD script updates text labels, and the Environment script plays sound effects when events arrive!

TRY IT YOURSELF

4. TRY CHANGING SOMETHING

Open the **Starter World** project in AeoEngine and press **Play**! Try adding a new sound object or a new trap block to see how easily new objects plug into this event flow!

5. COMMON BEGINNER MISTAKE

Mixing Gameplay and Presentation: Don't try to play sound effects or update HUD panels inside the Coin script directly. Using events keeps your scripts clean, modular, and easy to expand!
