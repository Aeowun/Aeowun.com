VALUES & VARIABLES

Store and change game information like health, gold, and player state.

LESSON 2

1. WHAT YOU'RE MAKING

Games need to remember things: how much health the player has, how many coins they collected, and whether the game is over. In this lesson, you'll create variables to hold player stats and update them when something happens.

CODE

2. WORKING EXAMPLE

AEOFILE PLAYER_STATE.AEO 
// const defines a value that shouldn't change
const max_health = 100

// Variables store numbers, text, and booleans
health = max_health
gold = 0
game_over = false

// Updating a variable when gold is picked up
gold += 10

debug.log("Health: " + health + " / " + max_health)
debug.log("Gold: " + gold)
BREAKDOWN

3. LINE-BY-LINE BREAKDOWN

`const max_health = 100`: Uses const to lock in the maximum health value so it won't be changed accidentally.

`health = max_health`: Sets the starting health to 100.

`gold += 10`: Adds 10 to the current `gold` variable. It's a shortcut for `gold = gold + 10`.

`"Health: " + health`: Uses `+` to join text strings and numbers together into one line.

TRY IT YOURSELF

4. TRY CHANGING SOMETHING

Try changing `const max_health = 100` to `200` or changing `gold += 10` to `gold += 50`. Run your script and see how the numbers update in the output console!

5. COMMON BEGINNER MISTAKE

Trying to Reassign a `const`: If you write `const max_health = 100` and later try `max_health = 150`, AeoEngine will stop with an error because `const` values are locked!

Misspelling Variable Names: AeoScript is case-sensitive. `health` and `Health` are treated as two completely different variables!
