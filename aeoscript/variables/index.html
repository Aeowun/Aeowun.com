VARIABLES & CONSTANTS

Storing and managing data using mutable variables and immutable constants.

AEOSCRIPT // FUNDAMENTALS

OVERVIEW

WHAT YOU'LL LEARN

  • — Declaring variables and constants
  • — Using const for immutability
  • — Type inference vs. explicit typing
  • — Scope and persistent state

CORE CONCEPT

Variables are mutable by default and can store any AeoScript type. Constants, declared with const, prevent re-assignment to the identifier. For reference-backed types like baskets and maps, const does not prevent internal mutation.

SYNTAX / WORKFLOW

EXAMPLES

DECLARATION SYNTAX 
identifier = value // Mutable variable
const name = value // Constant binding
health: number = 100 // Explicitly typed variable
CONSTANTS EXAMPLE 
health = 100
const MAX_HEALTH = 100

health -= 10

// MAX_HEALTH = 120 // ERROR: Cannot reassign constant

EXPLANATION: health is a mutable variable that can be decremented, while MAX_HEALTH is a constant that provides a safe, unchanging baseline for logic.

COMMON NOTES / LIMITATIONS

A variable must provide either a type annotation or an initializer.

For reference-backed collections (baskets/maps), const only prevents reassigning the variable itself, not mutating the collection's contents.

Use basket.freeze() when a collection itself must become truly immutable.
