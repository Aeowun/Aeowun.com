BASKETS

Managing ordered sequences of values with reference semantics.

AEOSCRIPT // COLLECTIONS

OVERVIEW

CORE CONCEPT

A basket is a zero-indexed, reference-backed sequence of values. Because they use reference semantics, assigning a basket to a new variable creates an alias rather than a copy. Mutating one alias is visible through every other reference to the same collection. Baskets are commonly returned by discovery functions like find().

SYNTAX / WORKFLOW

EXAMPLES

BASKET OPERATIONS SYNTAX 
items = ["Sword", "Shield"]
first = items[0]
basket.insert(items, 0, "Potion")
REFERENCE ALIASING EXAMPLE 
const ids = [1, 2]
const alias = ids

ids[0] = 99

debug.log(alias[0]) // Outputs 99
debug.log(basket.len(ids)) // Outputs 2

EXPLANATION: This example demonstrates reference semantics. Modifying ids[0] also changes alias[0] because both variables point to the same underlying basket. The basket.len function returns the number of elements.

COMMON NOTES / LIMITATIONS

Baskets are zero-indexed; the first element is at index 0.

Use basket.clone() to create a distinct shallow copy of a collection.

Use basket.freeze() to prevent further mutation of a basket.
