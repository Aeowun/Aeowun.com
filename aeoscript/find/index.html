OBJECT DISCOVERY

Locating authored World Cells and runtime Entities through name-based queries.

AEOSCRIPT // ENGINE

OVERVIEW

WHAT YOU'LL LEARN

  • — Searching for objects with find(name)
  • — Querying authored Cells by class
  • — Handling multiple search results in a basket
  • — Integrating discovery into gameplay logic

CORE CONCEPT

Object discovery allows scripts to dynamically locate engine objects. The find(name) function searches for authored World Cells and runtime Entities that match a human-readable identity. Because multiple objects can share the same name, discovery functions always return a collection of handles in a basket.

SYNTAX / WORKFLOW

EXAMPLES

DISCOVERY FUNCTIONS SYNTAX 
find(identity_name) // Returns basket of handles
getAllCellsOfClass(class_name) // Returns basket of authored Cells
SEARCH & ITERATE EXAMPLE 
const walls = find("Wall")
debug.log("Found", walls.len(), "walls.")

for wall in walls {
  wall.visible = false
}

const all_blocks = getAllCellsOfClass("Block")

EXPLANATION: find("Wall") returns a basket containing handles for every object named "Wall". The script can then iterate over this basket to modify each object, such as hiding all walls simultaneously.

COMMON NOTES / LIMITATIONS

find() matches both authored identity names and runtime Entity names.

Searching by name is convenient but can be ambiguous; use unique Cell IDs for stable instance targeting.

Discovery functions are typically more expensive than direct handle access; cache results when possible.
