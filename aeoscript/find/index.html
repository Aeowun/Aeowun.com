FINDING THINGS

Connect your scripts to objects placed in your 3D level using find().

LESSON 5

1. WHAT YOU'RE MAKING

Before a script can open a door or hide a coin, it needs to locate that item in your 3D World. In this lesson, you'll use `find("Name")` to locate objects by the names you gave them in the Editor!

CODE

2. WORKING EXAMPLE

AEOFILE FIND_OBJECTS.AEO 
// find() returns a list of all matching items in your World
const player = find("Player")[0]
const coins = find("Coin")

debug.log("Found player at position:", player.position)
debug.log("Total coins in level:", basket.len(coins))
BREAKDOWN

3. LINE-BY-LINE BREAKDOWN

`find("Player")`: Searches your 3D world for objects named `"Player"`. It returns a list (basket) of matching items.

`[0]`: Grabs the very first item from the search list.

`find("Coin")`: Grabs all objects named `"Coin"` so you can loop through them.

TRY IT YOURSELF

4. TRY CHANGING SOMETHING

Select a block in your AeoEngine editor, rename it to `"SecretDoor"` in the Properties panel, and run `const door = find("SecretDoor")[0]`. Log its `door.id` to verify you found it!

5. COMMON BEGINNER MISTAKE

Forgetting `[0]` on Single Objects: `find("Player")` returns a list. If you write `find("Player").position`, it will error. Write `find("Player")[0].position` to access the item inside the list!

Name Mismatch: If `find("Door")` returns `nil`, check the Editor Hierarchy to confirm the name is spelled identically.
