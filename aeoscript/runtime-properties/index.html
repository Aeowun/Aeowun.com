RUNTIME PROPERTIES

Modifying Cell visibility, solidity, color, offset, and physics properties during gameplay.

AEOSCRIPT // ENGINE

OVERVIEW

WHAT YOU'LL LEARN

  • — Controlling Cell visibility with cell.visible = false
  • — Toggling collision participation with cell.solid = false
  • — Changing static vs dynamic physics with cell.anchored
  • — Modifying visual color and offsets during live gameplay

CORE CONCEPT

In AeoEngine, scripts can modify Cell properties while the game is running. These changes affect the active play session as runtime overrides. Because they exist only during Play mode, stopping the game restores your original authored World intact.

PROPERTIES SPECIFICATION

SUPPORTED CELL PROPERTIES

Property Type Gameplay Usage
cell.visible bool Hide secret doors, vanish collected coins, or reveal hidden traps.
cell.solid bool Allow or block characters from walking through a doorway or bridge.
cell.anchored bool Unanchor a block to make it fall with physics when triggered.
cell.color basket Change RGB color `[r, g, b]` when activated or damaged.
cell.offset basket Smooth visual offset `[x, y, z]` for floating or bobbing animations.
cell.position basket Move runtime-created cells directly in 3D space.
cell.name string Update human-readable instance name during play.
SYNTAX / WORKFLOW

DOOR OPENING EXAMPLE

DOOR SCRIPT EXAMPLE 
const door = find("MainDoor")[0]

fn open_door() {
  if door {
    door.visible = false
    door.solid = false
    debug.log("Door opened!")
  }
}

fn close_door() {
  if door {
    door.visible = true
    door.solid = true
    debug.log("Door closed!")
  }
}

EXPLANATION: When open_door() is called, setting door.visible = false hides the door graphics and door.solid = false turns off physical collision so the player can walk through.

COMMON NOTES / TIPS

Play Session Scope: Runtime property changes last while the game is running and reset when Play mode stops.

Custom Attributes: For storing arbitrary variables (like health or gold) on a Cell, see Custom Attributes & Data.
