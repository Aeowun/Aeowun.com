OPERATORS

Performing calculations, comparisons, and logical operations on values.

AEOSCRIPT // FUNDAMENTALS

OVERVIEW

WHAT YOU'LL LEARN

  • — Arithmetic operators (+, -, *, /, %)
  • — Assignment and compound assignment
  • — Relational and equality operators
  • — Logical AND, OR, and NOT

CORE CONCEPT

Operators allow you to manipulate data and build complex expressions. AeoScript follows standard mathematical operator precedence, and the + operator is overloaded to support both numeric addition and string concatenation when types are compatible.

SYNTAX / WORKFLOW

EXAMPLES

EXPRESSIONS SYNTAX 
result = a + b * c
if health > 0 && !dead { ... }
counter += 1
DAMAGE CALCULATION EXAMPLE 
base_damage = 10
multiplier = 1.5
crit_chance = 0.2

total = base_damage * multiplier

if math.random() < crit_chance {
  total *= 2
}

EXPLANATION: This example calculates damage by multiplying base values and using a relational operator (<) to determine if a critical hit occurs via math.random(), then applies a compound assignment (*=).

COMMON NOTES / LIMITATIONS

Operator precedence: Unary > Multiplicative > Additive > Relational > Equality > Logical.

Parentheses can be used to explicitly control grouping in complex expressions.

Assignment operators include =, +=, -=, *=, and /=.
