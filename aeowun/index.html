WHAT IS AEOWUN?

AEOWUN is an independent software project building local-first tools and systems with an emphasis on control, verification, and understandable behavior.

SEE THE WORK GITHUB
THE IDEA

KEEP THE OPERATOR IN THE LOOP.

A useful system does not have to become a black box. I want the person using the software to be able to see what it has access to, what it changed, and what happened when something failed. That applies to small utilities as much as it does to AI-assisted systems.

CONTROL

PEOPLE DECIDE

A model or tool can propose an action. The runtime determines what is actually permitted, and restricted actions can require approval. MAGY is built around this distinction.

LOCAL-FIRST

KEEP DATA CLOSE

AEOPIN stores captured data locally. CheckMaker works with local files. MAGY is designed around a local model server instead of requiring a hosted AI service.

EVIDENCE

A MESSAGE IS NOT PROOF

MAGY can run verification after making a change and use the resulting output to determine what happened. A completion message is not a substitute for checking the result.

VERIFICATION

CHECK THE BOUNDARY

AEOPIN's Authority installer checks the expected package and payload before installing. CheckMaker can detect when a file has changed since it was last read.

SYSTEMS

UNDERSTAND FIRST

AEOWUN IDE is a VS Code fork with MAGY integrated into it. The point is to work with the source, filesystem, terminal, project information, and assistant in the same development environment.

STATUS

SAY WHAT EXISTS

A shipped application, an active project, an experiment, and a research idea are different things. AEOWUN labels them that way instead of presenting everything as finished software.

These projects are at different points. AEOPIN and CheckMaker are shipped. The IDE and MAGY are active development projects. AEIN is experimental. ZERO is research. The labels are there so it is clear which is which.

SHIPPED

PRODUCTS

AEOPIN and CheckMaker are Windows applications that can be used today. They are the parts of AEOWUN that have made it through the build-and-release process.

ACTIVE

SYSTEMS

AEOWUN IDE and MAGY are still being built. The IDE is a VS Code fork used to integrate and work on MAGY alongside normal development tools.

EXPERIMENTAL / RESEARCH

OTHER WORK

AEIN and ZERO are not shipped products. They are places to work through ideas around controlled machine operation, structure, constraints, and system behavior.

WHERE IT STANDS

THIS IS STILL A PROJECT.

AEOWUN is not a finished commercial platform. The public repositories contain released applications, active development trees, research code, experiments, and supporting work. Some parts are useful today. Some parts are still being figured out. The point of this site is to show that distinction rather than hide it behind a polished product catalog.

The code is public because I want the work to be useful beyond my own machine. Download it, read it, reverse engineer it, hypothesize about it, or build something from it.

The engineering record contains more detail about the work and the systems behind it.
