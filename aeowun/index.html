WHAT IS AEOWUN?

AEOWUN is an independent software project building local-first systems that keep you in control.

SEE THE WORK GITHUB
WHY CONTROL?

POWER WITHOUT SURRENDER.

Software can be useful and still leave the operator in charge of data, execution, and failure. AEOWUN is built for people who want local ownership, visible boundaries, and systems that do not hide what they did. The common denominator is not AI. It is control.

CONTROL

HUMAN AUTHORITY

A model or tool may propose. A person decides when a restricted action is allowed. MAGY pauses restricted writes for approval. AEIN explores the same idea for machine operations.

LOCAL-FIRST

USEFUL WITHOUT THE CLOUD

AEOPIN stores captured data on the computer that runs it. CheckMaker bundles assets locally. MAGY expects a local OpenAI-compatible model server rather than a hosted service.

EVIDENCE

CLAIMS ARE NOT COMPLETION

MAGY runs a verification command after changes and feeds failure output back into the loop. The runtime, not a completion message, decides whether work is done.

VERIFICATION

THE BOUNDARY IS THE PRODUCT

AEOPIN’s Authority installer checks the matching payload and fails closed when integrity checks do not pass. CheckMaker refuses stale writes when the file has drifted.

SYSTEMS

UNDERSTAND BEFORE YOU ACT

AEOWUN IDE is built around the project: source, filesystem, terminal, analysis, and persistent workspace state. Understanding the system comes before asking an assistant to change it.

HONEST STATUS

MATURITY IS LABELED

Shipped products, active systems, experiments, and research are not the same thing. A prototype is not presented here as a finished service.

AEOPIN is the first shipped AEOWUN product. CheckMaker is a second shipped utility. The IDE and MAGY are active systems. AEIN is experimental. ZERO is research. They are all built for control.

SHIPPED

PRODUCTS

AEOPIN and CheckMaker are both shipped Windows products. They are tools you can run today, not a catalog of future promises.

ACTIVE

SYSTEMS

AEOWUN IDE and MAGY are under active development. They show that AEOWUN is larger than a pair of utilities.

EXPERIMENTAL / RESEARCH

OPEN QUESTIONS

AEIN and ZERO are not downloadable products. They record direction: auditable action, and intelligence that needs structure.

ENGINEERING

AN ONGOING PROJECT.

AEOWUN is not a finished commercial platform. Public GitHub repositories include shipped tools, an IDE-related tree (AeowunV2), MAGY (publicly labeled as an emergency backup), ZERO research code, support tracking, and experimental tooling. Status belongs on the page, not behind a polished catalog. See the engineering record.
