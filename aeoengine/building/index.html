VOXEL BUILDING MODES

Construct geometric layouts efficiently using integrated Plane and Top-Block building operations.

AEOENGINE // FUNDAMENTALS

OVERVIEW

WHAT YOU'LL LEARN

  • — Toggling abstract workspace grid height boundaries in Plane mode
  • — Leveraging face-aware target snapping in Top-Block mode
  • — Configuring paint values via persistent color pickers
  • — Utilizing drag, line, and overwrite build mechanisms

CORE CONCEPT

Building geometry in AeoEngine utilizes contextual workspace brushes. Rather than clicking singular points exclusively, authors can stretch lines or planes with real-time ghost previews. The editor captures configured Block parameters (ColorRGB, TextureID) and maps them cleanly into the global grid persistence file.

WORKFLOW / CAPABILITIES

PAINTING MATRIX

Brushes adapt dynamically based on selection modes. Overwriting existing layout components is handled through explicit shortcut states. Core behaviors include:

VOXEL PAINTING MATRIX 
Voxel Painting Matrix:
- Plane Mode: Bounds brush creation strictly along a horizontal height baseline.
- Top-Block Mode: Targets visible voxel faces, providing automated vertical stacking.
- Shift + Build: Forces immediate property overwrite onto existing voxel indices.
- Ghost Preview: Draws wireframe bounds prior to committing construction buffers.

EXPLANATION: Drag operations support swift geometric sculpting. Color parameters are configured via precise numeric ColorRGB inputs or an integrated visual Color Picker widget, loading directly into persistent cell files.

COMMON NOTES / LIMITATIONS

Terminology: Legacy records are unified under the universal Block cell definition.

Undo Support: Full history tracing covers drag build, single stamp, brush erase, and cell delete operations.

Mesh Rendering Limits: Complex geometric calculations like greedy face meshing and culling are planned enhancements to optimize draw calls.
