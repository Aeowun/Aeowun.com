EDITOR WORKSPACE

Navigate the unified grid-based workspace and utilize advanced scene authoring panels.

CORE CONCEPT

The AeoEngine Editor presents a high-productivity workspace pairing a live 3D voxel viewport with docked management panels. By utilizing camera-ray-based picking and dedicated inspectors, it anchors a fluid pipeline for creating, selecting, and configuring world objects.

WORKFLOW / UTILITY

KEYBOARD CONFIGURATION

Authoring actions are mapped directly to workspace hotkeys. Selection indicators outline targets in the interactive grid plane. Essential shortcuts include:

EDITOR KEYBOARD CONFIGURATION 
Editor Keyboard Configuration:
- [Ctrl + S] Commit and Save World State
- [Delete]   Remove Targeted Workspace Cell
- [Ctrl + Z] Undo Last Construction Action
- [Ctrl + Y] Redo Reversed Construction Action
- [F]        Focus Viewport Camera on Active Selection
- [Esc]      Clear Active Selection References

EXPLANATION: Viewport selection utilizes precise camera-ray intersections against visible world voxel faces. Selected nodes instantly stream properties to the docked property inspector for real-time parameter tweaking.

COMMON NOTES / LIMITATIONS

State Continuity: The editor camera position is preserved perfectly when shifting between Editor and Play simulation transitions.

Input Gating: Input controls for the editor view are automatically locked during live simulation to prevent modification conflicts.

Undo Architecture: History tracking covers standard workspace construction actions, including block creation, erasing, and structural updates.
