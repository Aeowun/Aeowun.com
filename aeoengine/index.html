OVERVIEW

WHAT IS IT?

AeoEngine lets you build worlds in the editor and jump into Play mode to see them in action. Changes made while playing are temporary, so the world you're building stays intact.

THE WORKFLOW

AeoEngine is built around a simple cycle: BUILD the world, RUN the simulation, SCRIPT gameplay with AeoScript, TEST what happens, and IMPROVE what you make.

WORKING WITH AEOENGINE

PATHS

EDITOR Build, organize, and texture your world. RUNTIME Simulate physics, character movement, and lighting with AeoScript control. AEOSCRIPT Create gameplay interactions with persistent Cell-ID bindings, cooperative fibers, and runtime overrides.
