AEOENGINE

Voxel engine and editor for building authored worlds and running them with physics, lighting, characters, and gameplay scripts.

AEOENGINE OVERVIEW

WHAT IS IT?

AeoEngine provides a grid-based editor for creating authored worlds and a simulation runtime for playing them. It maintains a strict conceptual separation: Authored World data remains the persistent source of truth, while changes during Play mode are temporary runtime state.

THE WORKFLOW

AeoEngine is designed around a continuous cycle: AUTHOR authored scenes, BUILD the world, RUN the simulation, SCRIPT AeoScript gameplay logic, TEST the results, and IMPROVE the design.

WORKING WITH AEOENGINE

PATHS

EDITOR Author worlds with hierarchy, multi-selection, Plane building modes, and project-owned texture assets. RUNTIME Simulate physics, character movement, and lighting with dedicated gameplay camera and AeoScript control. AEOSCRIPT Implement interaction via persistent Cell-ID bindings, cooperative fibers, and runtime overrides.
