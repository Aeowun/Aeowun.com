MAKE YOUR FIRST WORLD

A step-by-step introduction to setting up AeoEngine, creating a project workspace, building geometry, and jumping into live Play mode.

AEOENGINE // FUNDAMENTALS

OVERVIEW

WHAT YOU'LL LEARN

  • — Creating and opening a project in the editor
  • — Creating a new project workspace and world file
  • — Sculpting floors and structures with voxel building tools
  • — Adding lighting, sky presets, and character spawn points
  • — Testing gameplay in real-time simulation mode

CORE CONCEPT

AeoEngine combines a 3D voxel editor with a fixed-step physics runtime. You author a World, enter Play mode to try it, and return to the same authored World when the session ends.

STEP 1

OPEN AEOENGINE

Start AeoEngine and wait for the Project Manager. This beginner guide begins in the editor; you do not need to understand the engine source code to make a World.

DEVELOPER NOTE: If you are building AeoEngine itself from source, use the build instructions in the project repository. That is a separate workflow from creating a game project.

STEP 2

CREATE A PROJECT WORKSPACE

Upon launching, you are presented with the Project Manager screen:

WORKFLOW PROJECT CREATION 
1. Click 'New Project' on the home launcher.
2. Enter a project name (e.g. "MyFirstWorld").
3. Choose where to save the project.
4. Select the project and open its workspace.
STEP 3

BUILD YOUR ENVIRONMENT

With the workspace open, use the building tools to construct your terrain and buildings:

  • 1. Choose a Grid Plane: Select the XZ, YZ, or XY grid plane that matches the surface you want to build.
  • 2. Build a Simple Shape: Use the Build tool to place Cells. Click to place one Cell, or drag to create a rectangular range. When building against a Cell, placement follows the face you selected; hold Shift to place in the selected Cell instead.
  • 3. Erase & Modify: Use Erase to remove Cells and Select to inspect one or more Cells. Undo and redo restore authored world edits.
STEP 4

SET SKY, LIGHTS & SPAWN POINT

Bring your world to life with environment settings and player entry points:

SKY PRESETS

Open the Environment panel and choose a sky preset like Temperate, Tropical, Desert, Snowy, or Mars to instantly change the atmosphere.

AUTHORED LIGHTS

Select the Light tool to place point light cells on walls or ground blocks. Customize light colors and intensity in the Properties panel.

SPAWN POINT

Select the Spawn Point tool and place a spawn cell on your floor. This marks where your character will spawn when entering Play mode.

STEP 5

TEST IN PLAY MODE

Choose Play to start a test session. The editor saves its camera state before Play and restores it when the session ends.

PLAY MODE WHAT CHANGES 
- The active controller reads movement and jump input.
- Your project can use a third-person or first-person gameplay camera.
- World mouse settings set the initial cursor and screen-lock behavior.
- Stop Play mode to return to editing.

TEMPORARY STATE: Any changes or movements during Play mode are temporary runtime states. Pressing Stop cleanly resets the world back to your authored world.dat design.

REQUIREMENTS & SPECIFICATIONS

World Data: Authored Cells are stored sparsely at integer world coordinates and are saved with the project.

Cell Types: The editor supports Blocks, FxBlocks, Players, NPCs, Lights, SpawnPoints, and AudioEmitters.

Documentation Scope: This page describes the AeoEngine 0.7.3 implementation snapshot.
