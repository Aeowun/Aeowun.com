GETTING STARTED

Set up the AeoEngine development environment and launch your first voxel workspace.

CORE CONCEPT

AeoEngine is built entirely on the Rust stable toolchain, enabling high-performance voxel rendering and simulation directly on Windows. The engine workspace operates with local project ownership, combining the 3D voxel editor and simulation runtime into a unified local environment.

WORKFLOW / UTILITY

BUILDING & RUNNING

To compile and initialize the workspace environment, navigate to your local workspace root and use the standard Rust package manager commands to trigger the compilation chain.

TERMINAL CARGO 
# Verify toolchain installation
rustc --version

# Compile and run the workspace application
cargo run

EXPLANATION: Executing cargo run builds the voxel world representation, editor viewport, asset management pipelines, and scripting runtime libraries. Once complete, it immediately launches the desktop interface.

COMMON NOTES / LIMITATIONS

Platform Requirement: Supported exclusively on Windows 10 or Windows 11.

Toolchain Requirement: Requires the latest stable Rust distribution.

Development Status: Current development is in the active 0.7.x phase, focusing on live application testing and workflow integration problems.
