FAQ

What is AEOWUN? +
AEOWUN is an independent software project building local-first systems for controlled computing. AEOPIN and CheckMaker are shipped products. The IDE and MAGY are active systems. AEIN is experimental. ZERO is research.
What can I download today? +
Two Windows releases are public: AEOPIN v1.2.3 and CheckMaker v1.0.0. Both are available from verified GitHub releases. Other AEOWUN work is inspectable on GitHub and is not presented as finished downloads.
Do I need an account? +
No AEOWUN account is required for AEOPIN or CheckMaker. MAGY expects a local OpenAI-compatible model server, such as LM Studio, rather than an AEOWUN login.
Where is data stored? +
AEOPIN keeps captured data locally under Documents/AEOPIN. CheckMaker edits Markdown files you open and stores recent-file history locally. MAGY works against a project directory you select on your machine.
Is my data sent anywhere? +
AEOPIN and CheckMaker are designed as local Windows tools and do not upload your files to AEOWUN servers. MAGY talks to a local model server you configure. This website may load advertising scripts; that is separate from the desktop applications. See the privacy policy.
Do the apps show ads? +
AEOPIN does not display advertisements inside the application. CheckMaker’s published description does not include in-app ads. This website can show sponsored units.
Which Windows versions? +
AEOPIN is built for Windows 10 and Windows 11. CheckMaker’s public release is a standalone Windows executable.
How do I report a problem? +
Use the report page and open an issue on the GitHub repository for the software you are using. Do not include passwords, private files, tokens, or confidential information.
