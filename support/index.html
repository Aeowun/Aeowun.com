FAQ

What is AEOWUN? +
AEOWUN is an independent software project building local-first tools and systems. AEOPIN and CheckMaker are shipped products. AEOWUN IDE and MAGY are active development projects. AEIN is experimental. ZERO is research.
What can I download today? +
Two Windows applications are currently published: AEOPIN v1.2.3 and CheckMaker v1.0.0 . Other AEOWUN work is available for inspection through the public GitHub repositories but is not presented as a finished downloadable product.
Do I need an AEOWUN account? +
No AEOWUN account is required for AEOPIN or CheckMaker. MAGY can use different model configurations, including local models, local model servers, and external model providers. An AEOWUN account is not the definition of the MAGY system.
Where is my data stored? +
AEOPIN stores captured data locally on your computer. CheckMaker works with the Markdown files you open and keeps its application state locally. MAGY operates against the project and model configuration you choose.
Is my application data sent anywhere? +
AEOPIN and CheckMaker are designed as local Windows applications and do not upload your files to AEOWUN-operated servers as part of their normal core workflows. MAGY is different because a MAGY configuration can use an external model provider if you choose one. In that case, data sent to that provider is governed by that provider's service and configuration. The AEOWUN website is separate from the desktop applications and may load third-party advertising services. See the privacy policy .
Do the applications show ads? +
AEOPIN and CheckMaker do not display advertisements inside the applications. The AEOWUN website may display sponsored advertising separately from the desktop software.
Which Windows versions? +
AEOPIN is built for Windows 10 and Windows 11. CheckMaker's public release is a standalone Windows executable.
How do I report a problem? +
Use the report page and include the relevant software and version. GitHub issues can also be used for repositories that accept public issue reports. Do not include passwords, private files, tokens, or confidential information.
Where can I read about privacy? +
The privacy policy covers the current data practices of AEOPIN and CheckMaker and distinguishes those applications from the AEOWUN website.
