FAQ

What is AEOPIN? +
AEOPIN is a professional Windows capture appliance designed for one simple idea: Capture immediately, find later. It takes physical possession of your originals and preserves them in a secure local vault.
Is AEOPIN free? +
AEOPIN is free for Windows. It is currently in active development.
Does AEOPIN require an account? +
No. AEOPIN is 100% local-first. Everything stays on your computer. No cloud, no tracking, no accounts required.
Where is data stored? +
Your authoritative data is kept locally in Documents/AEOPIN.
Is my data sent anywhere? +
No. AEOPIN operates entirely on your local machine. Files are never transmitted to external servers.
Does it show ads? +
AEOPIN itself contains no advertisements.
Supported Windows versions? +
AEOPIN is built for Windows 10 and Windows 11.
How do I report a problem? +
Please use the Report a Bug page to submit an issue via our GitHub repository.
